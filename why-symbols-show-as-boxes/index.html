Symbols

Why symbols show as boxes

You copy a neat arrow or a rupee sign, send it, and your friend sees a hollow box. Or you open a file and every quotation mark has turned into three odd letters. Both problems have simple causes. Knowing them tells you what to do.

How symbols work: number first, picture second

To a computer, every character is a number. The capital letter A is 65; the rupee sign is 8377; the red heart is 10084. A worldwide standard called Unicode decides which number belongs to which character, so that a message written on one device means the same on another. The numbers are usually written in base sixteen with "U+" in front: U+20B9 for ₹.

A number is not a picture. To draw the character, the device looks in a font, which is a file of drawings, one for each number it supports. No font has drawings for everything. When the font in use has no drawing for a number, the device tries other fonts. If none has it, you get the box.

Problem 1: a box, sometimes with a cross or tiny digits inside

The character arrived correctly, but the receiving device has no drawing for it. This happens when:

  • The character is newer than the device. Unicode adds characters every year. A phone that has not been updated for some years does not know the newest emoji and signs. The rupee sign, added in 2010, was a box on many older computers for years.
  • The character is rare. Musical clefs, old scripts and some technical signs are missing from many phones.
  • The app forces one font. Some programs and websites do not fall back to other fonts.

What to do: the sender can choose a more common symbol (the plain ♥ instead of a new coloured heart, "Rs" instead of ₹ for a very old device). The receiver can update the system or, on a computer, change the font to one with wide coverage, such as Segoe UI Symbol on Windows or Noto Sans Symbols anywhere.

Problem 2: a question mark, or a black diamond with a question mark (�)

Here the number itself was damaged. Somewhere between sender and receiver, a program that did not understand the character replaced it. Old SMS systems, some forms on websites, and files saved in an old format do this. Once it has happened the original cannot be recovered; send it again by a different route, or save the file as UTF-8.

Problem 3: strange letters such as â€™ or Ã©

This is called mojibake. The text was stored correctly in the modern encoding, UTF-8, where an unusual character takes two or three bytes, but it was opened as if it were in an older one-byte encoding. Each byte was then shown as a separate letter. A curly apostrophe becomes â€™ and é becomes Ã©. The fix is to open the file again and choose UTF-8 as the encoding. In Excel, use Data › From Text/CSV and pick "65001: Unicode (UTF-8)" instead of double-clicking a CSV file. On a web page, add <meta charset="utf-8">.

Why the same symbol looks different on two phones

Unicode fixes the number and the meaning, not the drawing. Each company draws its own font and its own emoji. A smiling face sent from an Android phone is the same number on an iPhone but a different picture. Even plain signs differ in weight and shape between fonts.

Why some symbols turn into coloured pictures

A few hundred older symbols, such as ❤ ☀ ☎ ✔ ⚠, were later also declared to be emoji. They have two presentations, plain text and coloured picture, and each app chooses a default. Phones prefer the picture. An invisible character placed after the symbol can request one form or the other, but many apps ignore it. If you need a plain symbol that follows the colour of your text, choose one that has no emoji form.

A short checklist before sending symbols to many people

  1. Prefer symbols that have existed for a long time; the sets on this site put the common ones first.
  2. Test the message on one Android phone and one iPhone if you can.
  3. Never let a symbol carry the whole meaning. "✓ Done" is safe; "✓" alone is not.
  4. In documents that others will open on unknown computers, send a PDF: it carries its fonts with it.
