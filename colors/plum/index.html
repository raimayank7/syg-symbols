About plum

Plum, as a web colour, is a soft light purple. The fruit it is named after is much darker, and in fashion "plum" usually means that darker reddish purple.

How to mix plum in paint

For the web colour, add purple to white with a trace of red. For the darker fashion plum, mix purple with red and a little black.

How plum is made on a screen

A screen mixes red, green and blue light. For plum it uses red 221, green 160 and blue 221 on a scale of 0 to 255, which is 87%, 63% and 87% of full strength. The red and blue lights are equally strong and the green light is weaker, which puts the colour midway between them.

In HSL terms its hue is 300°, exactly at magenta on the colour wheel. Its saturation is 47%, which makes it fairly strong, and its lightness is 75%, so it is light.

Lighter and darker plum

Tints are made by adding white, shades by adding black. Tap a box to copy its code.

Text on plum

White text on plum has a contrast ratio of 2.06 : 1 and black text has 10.14 : 1, so black text is the one to use. That is strong enough for text of any size.

White textBlack textPlum on white

As text on a white page, plum has a contrast of 2.06 : 1. It is too faint to read: use it for shapes and backgrounds, not for words. Check any pair in the contrast checker.

Similar named colours

The closest of the 148 named web colours to plum are thistle (#d8bfd8), violet (#ee82ee), orchid (#da70d6), lightpink (#ffb6c1) and pink (#ffc0cb).

Using it in a web page

color: plum;
background: #dda0dd;

The name and the hex code mean exactly the same colour to a browser. For print, the simple CMYK conversion is cmyk(0%, 28%, 0%, 13%), but a print shop's own figures will differ: see RGB and CMYK.

Common questions

What is the hex code of plum?

The web colour plum has the hex code #dda0dd, which is rgb(221, 160, 221).

What colours make plum?

For the web colour, add purple to white with a trace of red. For the darker fashion plum, mix purple with red and a little black.

What is the opposite of plum?

On the screen colour wheel the opposite of plum is #a1dda1, close to the web colour lightgreen.

Should text on plum be black or white?

Black text. Its contrast on plum is 10.14 : 1, against 2.06 : 1 for white.
