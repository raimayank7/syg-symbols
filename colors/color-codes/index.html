Colour codes explained: HEX, RGB, HSL and CMYK

A screen makes every colour from three lights: red, green and blue. A colour code is simply a way of writing down how strong each light should be. This page explains the common codes, how to read them and how to change one into another by hand.

RGB: three numbers from 0 to 255

In rgb(255, 165, 0) the first number is red, the second green and the third blue. Each runs from 0 (off) to 255 (full). So this colour is full red, about two thirds green and no blue: orange. There are 256 × 256 × 256 = 16,777,216 possible colours.

  • rgb(0, 0, 0) is black: all lights off.
  • rgb(255, 255, 255) is white: all lights full.
  • Three equal numbers always give a grey.

HEX: the same three numbers in base 16

A hex code such as #ffa500 is RGB written in hexadecimal, the base-16 counting used by computers. It has three pairs of digits: ff, a5, 00 for red, green and blue. Hexadecimal uses the digits 0 to 9 and then a to f for ten to fifteen.

Hex to RGB by hand. Multiply the first digit of a pair by 16 and add the second. For a5: a is 10, so 10 × 16 + 5 = 165. For ff: 15 × 16 + 15 = 255. So #ffa500 is rgb(255, 165, 0).

RGB to hex by hand. Divide by 16. The whole part is the first digit and the remainder the second. 165 ÷ 16 = 10 remainder 5, which is a5.

A three-digit code is a short form in which each digit is doubled: #f80 means #ff8800. Capital and small letters mean the same.

HSL: hue, saturation, lightness

RGB is how the screen works, but it is not how people think. hsl(39, 100%, 50%) describes the same orange in a friendlier way.

  • Hue is the position on the colour wheel in degrees: 0 red, 60 yellow, 120 green, 180 cyan, 240 blue, 300 magenta.
  • Saturation is how strong the colour is: 100% is vivid, 0% is grey.
  • Lightness runs from 0% (black) through 50% (the pure colour) to 100% (white).

HSL makes changes easy. To get a lighter version of a colour, raise the lightness. To get a matching colour, change only the hue. That is how palette tools work.

HSV or HSB

Drawing programs often use HSV (hue, saturation, value), also called HSB (brightness). The hue is the same as in HSL. The difference is that 100% value is the brightest form of the colour, not white.

CMYK: for printing

Printers do not shine light. They lay down cyan, magenta, yellow and black ink, each from 0% to 100%. The simple conversion from RGB shown on this site gives a starting point. A real printed colour depends on the paper, the ink and the printer's colour profile, so a print shop's proof is the only sure guide. More on RGB and CMYK.

Which code should I use?

  • Web pages and apps: hex is the most common. HSL is handy when you want to adjust colours.
  • Photo and drawing programs: RGB or HSV, with hex for copying.
  • Printing: CMYK values agreed with your printer.
  • Telling a person: a name, with the hex code to be exact.
