About maroon

Maroon is a dark brownish red. The name comes from the French word for chestnut. It is a common colour of school uniforms, blazers and sarees, and it reads as rich and serious where bright red would be loud.

How to mix maroon in paint

Add a little black or dark brown to red. A touch of blue pushes it towards burgundy and wine.

How maroon is made on a screen

A screen mixes red, green and blue light. For maroon it uses red 128, green 0 and blue 0 on a scale of 0 to 255, which is 50%, 0% and 0% of full strength. The red light is the strongest and the blue light the weakest.

In HSL terms its hue is 0°, exactly at red on the colour wheel. Its saturation is 100%, which makes it vivid, and its lightness is 25%, so it is dark.

Tints are made by adding white, shades by adding black. Tap a box to copy its code.

Text on maroon

White text on maroon has a contrast ratio of 10.94 : 1 and black text has 1.91 : 1, so white text is the one to use. That is strong enough for text of any size.

Similar named colours

The closest of the 148 named web colours to maroon are darkred (#8b0000), firebrick (#b22222), brown (#a52a2a), saddlebrown (#8b4513) and sienna (#a0522d).

Using it in a web page

color: maroon;
background: #800000;

The name and the hex code mean exactly the same colour to a browser. For print, the simple CMYK conversion is cmyk(0%, 100%, 100%, 50%), but a print shop's own figures will differ: see RGB and CMYK.

Common questions

What is the hex code of maroon?

The web colour maroon has the hex code #800000, which is rgb(128, 0, 0).

What colours make maroon?

Add a little black or dark brown to red. A touch of blue pushes it towards burgundy and wine.

What is the opposite of maroon?

On the screen colour wheel the opposite of maroon is #008080, close to the web colour teal.

Should text on maroon be black or white?

White text. Its contrast on maroon is 10.94 : 1, against 1.91 : 1 for black.
