Colour names and their codes

The 148 colour names that every web browser understands, with a sample of each and its HEX and RGB codes.

About this list

These are the named colours of the web standard, the W3C CSS Color Module. A web page can use any of these names in place of a code, and every browser shows the same colour for it. The list grew over many years, which is why it has several kinds of pink and green but only one teal, and why some names are odd, such as papayawhip and dodgerblue.

Below, the colours are sorted into nine families by hue, and within each family from light to dark. The sorting is done by our program from the codes, so a pale or greyish colour may sit in a family you would not expect. Type part of a name or a code in the box to find a colour, and tap a sample to copy its HEX code. Names that are links have a page of their own.

A few names are doubles for the same colour: aqua and cyan and fuchsia and magenta. The spellings gray and grey are both accepted wherever they appear.

Things worth knowing

  • The name "green" is a dark green. The brightest green is called lime.
  • Darkgray is lighter than gray. The names came from two different older lists, and the clash was kept.
  • The names are one word, with no spaces: lightblue, not light blue. Capital letters do not matter.
  • Not every colour has a name. There are over 16 million colours in the RGB system and only 148 names. For any other colour, use its code.
  • The names are for screens. A paint, a fabric or a printing ink sold under the same name will usually be a slightly different colour.
