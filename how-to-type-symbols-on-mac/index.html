How to type symbols on a Mac

A Mac hides a second and third keyboard under the Option key, and has a searchable viewer for everything else. Once you know the four methods below you will rarely need to copy a symbol again.

1. The Option key

Hold Option (also marked Alt or ⌥) and press a key to get a symbol; hold Option + Shift for another. These are the most useful ones on the standard US layout (the British layout differs in a few keys, such as £ and #):

The shortcuts depend on the keyboard layout chosen in System Settings › Keyboard › Input Sources. To see what every key gives on your own layout, turn on "Show Input menu in menu bar", then choose "Show Keyboard Viewer" from that menu: an on-screen keyboard appears, and it changes as you hold Option or Shift.

2. Hold a key for accents

Hold a letter key for a moment and a small bar of accented forms appears above it, each with a number. Press the number. Hold e and press 2 for é. This works for most vowels and for c, n, s and a few more.

There is an older method too, the "dead key": Option + E, then a vowel, gives an acute accent (é); Option + ` gives a grave (è); Option + I a circumflex (ê); Option + U an umlaut (ü); Option + N a tilde (ñ).

3. The Character Viewer

Press Control + Command + Space. A panel of emoji opens. Type a word in its search box, such as "arrow", "check" or "rupee", and matching symbols appear. Click the small icon at the top right to open the full viewer, with groups for arrows, bullets and stars, currency, Latin, maths, punctuation and more. Double-click a symbol to insert it. Symbols you use often can be added to Favourites.

On Macs with a Globe (🌐) key, pressing that key can open the same panel.

4. Text replacements

For a symbol you type daily, make your own shortcut. Open System Settings › Keyboard › Text Replacements and add a pair: replace ->> with →, or rs. with ₹. From then on, typing the short form and a space inserts the symbol. If you use the same Apple account on an iPhone, the replacements appear there as well.

The rupee sign on a Mac

The standard US layout has no key for ₹. The simplest ways are the Character Viewer (search "rupee") or a text replacement. Apple also offers an "ABC – India" input source, on which Option + 4 gives the rupee sign in place of the cent sign.

Symbols for Mac keys themselves

Menus and help pages show keys as signs: ⌘ Command, ⌥ Option, ⇧ Shift, ⌃ Control, ⎋ Escape, ⏎ Return, ⌫ Delete, ⇥ Tab. You can copy all of them from the units and technical set.

When a symbol shows as a box or a question mark

The font in use has no drawing for that character. macOS normally borrows one from another font automatically; if it does not, the character is very new or the app has forced a font. See why symbols show as boxes.
