More about it

What is in this set

A keyboard has plus, minus, equals and little else. Everything a student or teacher needs beyond that is here: the true multiplication and division signs, not-equal and approximately-equal, less-or-equal and greater-or-equal, roots, infinity, the signs of set theory and logic, the calculus signs, and the letters used for number sets.

How to use them well

Two details are worth knowing. The proper minus sign (−) is wider than the hyphen on your keyboard and lines up with the plus sign; use it in printed work. The multiplication sign (×) is not the letter x: a screen reader says "times" for one and "ex" for the other. In a spreadsheet or a program, though, you must still type the keyboard characters * and / because formulas do not understand × and ÷. If you write maths often, the LaTeX names shown on the pages of single symbols, such as \times and \leq, are worth learning.

Windows Alt codes in this set

15 of these symbols can be typed on a Windows PC by holding Alt and typing a number on the number pad: × is Alt + 0215, ÷ is Alt + 246, ± is Alt + 241, ≈ is Alt + 247, ≡ is Alt + 240, ≤ is Alt + 243, ≥ is Alt + 242, ∞ is Alt + 236, √ is Alt + 251, ∩ is Alt + 239. How it works, and the full list, is on the Alt codes page.

If a symbol shows as a box

Your device has no drawing for it in its fonts. Newer phones show nearly all of these; the reasons and fixes are in why symbols show as boxes.
