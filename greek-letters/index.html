Greek Letters to copy and paste

49 symbols. Tap one to copy it; its name and codes appear at the bottom of the screen.

More about it

What is in this set

The full Greek alphabet, capital letters first and then small letters: alpha, beta, gamma, delta and on to omega. Students meet them everywhere: π in circles, θ for angles, Δ for change, Σ for sums, λ for wavelength, μ for "micro", Ω for ohms, α and β for angles and particles.

How to use them well

Some Greek capitals look exactly like English letters (Α, Β, Ε, Κ, Μ, Ν, Ο, Ρ, Τ, Χ) but are different characters, which matters in passwords, searches and code. For units, Unicode also has special copies of two letters, the micro sign (µ) and the ohm sign (Ω); today the plain Greek letters are recommended instead. In Word you can type a Greek letter by choosing the Symbol font, or type its code and press Alt + X. In LaTeX each letter is its name after a backslash: \alpha, \Omega.

Windows Alt codes in this set

12 of these symbols can be typed on a Windows PC by holding Alt and typing a number on the number pad: Γ is Alt + 226, Θ is Alt + 233, Σ is Alt + 228, Φ is Alt + 232, Ω is Alt + 234, α is Alt + 224, δ is Alt + 235, ε is Alt + 238, π is Alt + 227, σ is Alt + 229. How it works, and the full list, is on the Alt codes page.

If a symbol shows as a box

Your device has no drawing for it in its fonts. Newer phones show nearly all of these; the reasons and fixes are in why symbols show as boxes.
