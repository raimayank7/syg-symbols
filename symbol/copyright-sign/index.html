Copyright sign ©: copy, meaning and codes

Copy the copyright sign with one tap, see what it means and how to type it on Windows, Mac, Android and iPhone, with its Unicode, HTML and CSS codes.

©

Copyright sign
U+00A9

What it means and how to use it

The letter C in a circle marks a work as protected by copyright. A typical notice has three parts: the sign, the year of first publication and the name of the owner, as in © 2026 Asha Verma. In India and most other countries copyright exists from the moment a work is created, so the notice is not what creates the right; it tells readers who owns the work and from when. If the sign is not available, the word "Copyright" does the same job; "(c)" in brackets is a common stand-in.

How to type it on Windows

Hold the Alt key, type 0169 on the number pad at the right of the keyboard, and let go of Alt. Type the zero at the front: without it you get a different character. Num Lock must be on, and the number keys above the letters do not work for this. In Word, Outlook and WordPad you can type 00A9 and then press Alt + X. In any program, press the Windows key and the full stop together to open the symbol panel and search for it.

How to type it on a Mac

Press Option + G on the standard US layout. Or press Control + Command + Space to open the Character Viewer and type "copyright" in its search box.

On Android and iPhone

Phone keyboards keep the common signs on the symbols pages (?123 on Android, 123 then #+= on iPhone), and many more appear when you hold a related key. If you cannot find this one, tap Copy on this page and paste it into your app.

In a web page

If your page is saved as UTF-8, you can paste © straight into the HTML. To be safe in any encoding, write its code instead: <p>&copy;</p>. In a style sheet use content: "\00A9", and in JavaScript "\u00A9".

If it shows as a box

The official Unicode name of this character is "copyright sign". A device or font that has no drawing for it shows an empty box instead; the character is still there and will appear correctly for readers whose devices have it. See why symbols show as boxes.
