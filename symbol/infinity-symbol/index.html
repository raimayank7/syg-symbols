Infinity symbol ∞: copy, meaning and codes

Copy the infinity symbol with one tap, see what it means and how to type it on Windows, Mac, Android and iPhone, with its Unicode, HTML and CSS codes.

∞

Infinity symbol
U+221E

What it means and how to use it

The sideways figure of eight stands for infinity: something without any limit. It is not a number, so it cannot be added or divided like one; in maths it describes how a quantity grows or how far a list continues. The English mathematician John Wallis introduced the sign in 1655. Outside maths it is a popular sign for "forever" on cards and jewellery.

How to type it on Windows

Hold the Alt key, type 236 on the number pad at the right of the keyboard, and let go of Alt. Num Lock must be on, and the number keys above the letters do not work for this. In Word, Outlook and WordPad you can type 221E and then press Alt + X. In any program, press the Windows key and the full stop together to open the symbol panel and search for it.

How to type it on a Mac

Press Option + 5 on the standard US layout. Or press Control + Command + Space to open the Character Viewer and type "infinity" in its search box.

On Android and iPhone

Phone keyboards keep the common signs on the symbols pages (?123 on Android, 123 then #+= on iPhone), and many more appear when you hold a related key. If you cannot find this one, tap Copy on this page and paste it into your app.

In a web page

If your page is saved as UTF-8, you can paste ∞ straight into the HTML. To be safe in any encoding, write its code instead: <p>&infin;</p>. In a style sheet use content: "\221E", and in JavaScript "\u221E".

If it shows as a box

The official Unicode name of this character is "infinity". A device or font that has no drawing for it shows an empty box instead; the character is still there and will appear correctly for readers whose devices have it. See why symbols show as boxes.
