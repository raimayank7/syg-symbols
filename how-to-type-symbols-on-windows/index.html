How to type symbols on Windows

A Windows keyboard shows about a hundred characters, and Windows can display well over a hundred thousand. There are five ways to reach the rest. Pick the one that suits how often you need a symbol.

1. Copy and paste

For a symbol you need once, this is the quickest. Find it on this site, tap it, and press Ctrl + V where you want it. Nothing to remember.

2. The emoji and symbol panel (Windows 10 and 11)

Press the Windows key and the full stop (.) together. A small panel opens at the cursor. It has emoji, and under the tab marked with symbols (Ω) it has currency signs, arrows, maths signs, Latin letters with accents and more. You can type a word such as "arrow" to search. Click a symbol to insert it. This works in almost every program.

3. Alt codes

The oldest method, and still the fastest for symbols you use daily:

  1. Make sure Num Lock is on.
  2. Hold down the left Alt key.
  3. Type the code on the number pad at the right of the keyboard. The row of numbers above the letters does not work.
  4. Let go of Alt. The symbol appears.

There are two families of codes, and the leading zero matters. Alt + 0176 gives the degree sign °, while Alt + 176 gives a shaded block ░. Codes without a zero come from the character set of the first IBM PC; codes with a zero come from the Western European set of Windows. The page of Alt codes lists both in full.

Laptops without a number pad are the usual stumbling block. Some have a hidden pad on the letter keys, switched on with an Fn key; many modern ones do not. If yours has none, use method 2 or 4.

4. A code and Alt + X (Word, Outlook, WordPad)

Every character has a Unicode number, written like U+20B9. In Microsoft Word, Outlook and WordPad, type the four or five characters after the plus sign and then press Alt + X: the code turns into the symbol. Type 20B9, press Alt + X, and you have ₹. Press Alt + X again and it turns back into the code, which is a handy way to find out what a strange character is. Each symbol page on this site gives this code.

5. Character Map

Open the Start menu and type "Character Map". This old tool shows every character in a font. Tick "Advanced view" to search by name. Select a symbol, press Copy, and paste it. It is slow, but it works when everything else fails and it needs no internet.

A better way for symbols you type all day

  • AutoCorrect in Word. Word already turns (c) into ©, (r) into ®, (tm) into ™ and --> into an arrow. You can add your own pairs under File › Options › Proofing › AutoCorrect Options.
  • A keyboard layout. With the "English (India)" layout, Ctrl + Alt + 4 (or the right Alt key + 4) types ₹. The "United States-International" layout turns the right Alt key into a symbol key for é, ñ, ü, € and others. Layouts are added under Settings › Time & language › Language & region.
  • Text shortcuts on the clipboard. Windows key + V opens the clipboard history; you can pin symbols you copied so that they are always there.

When a symbol shows as an empty box

The symbol is there, but the font cannot draw it. Change the font to Segoe UI Symbol or Segoe UI Emoji, which cover most signs. More on this in why symbols show as boxes.
