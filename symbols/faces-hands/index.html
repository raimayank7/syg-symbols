Symbols

Smiley Face and Hand Symbols to copy and paste

26 symbols. Tap one to copy it; its name and codes appear at the bottom of the screen.

More about it

What is in this set

The original text smileys (☺ ☻ ☹), pointing hands from old printing (☚ ☛ ☜ ☞ ☟), the victory and writing hands, and a short row of the most used emoji faces and gestures.

How to use them well

The smiling face ☺ is one of the oldest symbols in computing: it is character number 1 of the first IBM PC, which is why Alt + 1 still types it on Windows, and Alt + 2 types ☻. The pointing hands, called "manicules" or "printer's fists", were used in books for centuries to say "note this". Emoji look different on Android, iPhone and Windows, because each company draws its own set from the same code. If the exact look matters, send a picture instead. For the full emoji keyboard on Windows press the Windows key and the full stop together.

Names of the first symbols

Every symbol has an official name in the Unicode standard. Knowing the name helps when you search for it on a phone or in a program's symbol picker.

  • ☺ white smiling face
  • ☻ black smiling face
  • ☹ white frowning face
  • ☝ white up pointing index
  • ✌ victory hand
  • ✍ writing hand
  • ☚ black left pointing index
  • ☛ black right pointing index
  • ☜ white left pointing index
  • ☞ white right pointing index
  • ☟ white down pointing index
  • 👍 thumbs up sign
  • 👎 thumbs down sign
  • 👏 clapping hands sign

Windows Alt codes in this set

2 of these symbols can be typed on a Windows PC by holding Alt and typing a number on the number pad: ☺ is Alt + 1, ☻ is Alt + 2. How it works, and the full list, is on the Alt codes page.

If a symbol shows as a box

Your device has no drawing for it in its fonts. Newer phones show nearly all of these; the reasons and fixes are in why symbols show as boxes.
