More about it

What is in this set

Arrows are the most copied symbols on the web after the heart. This set has the four plain arrows, the diagonal ones, double arrows for "implies" and "if and only if" in maths and logic, curved arrows for "undo", "redo" and "return", and the heavier arrows that stand out in headings, menus and social media posts.

How to use them well

Use a plain arrow (→) in running text, for steps such as Settings → Display → Brightness. It reads better than a hyphen and a greater-than sign typed together. The double arrow (⇒) belongs to maths and should not replace the plain one in ordinary writing. The thick arrows (➜ ➤) may be drawn as coloured pictures on some phones, so check how a message looks before you send it to a large group. On Windows, Alt + 24, 25, 26 and 27 on the number pad give ↑ ↓ → ← in many programs.

Windows Alt codes in this set

10 of these symbols can be typed on a Windows PC by holding Alt and typing a number on the number pad: ← is Alt + 27, ↑ is Alt + 24, → is Alt + 26, ↓ is Alt + 25, ↔ is Alt + 29, ↕ is Alt + 18, ▲ is Alt + 30, ▼ is Alt + 31, ► is Alt + 16, ◄ is Alt + 17. How it works, and the full list, is on the Alt codes page.

If a symbol shows as a box

Your device has no drawing for it in its fonts. Newer phones show nearly all of these; the reasons and fixes are in why symbols show as boxes.
