Symbols

Box Drawing and Block Symbols to copy and paste

45 symbols. Tap one to copy it; its name and codes appear at the bottom of the screen.

More about it

What is in this set

Lines, corners and joints that fit together to draw boxes and tables out of text, plus shaded and solid blocks. Programmers use them for folder trees and terminal screens; they were the way to draw a window before graphics.

How to use them well

These only line up in a fixed-width font such as Consolas, Courier New or the font of a code editor, where every character has the same width. In an ordinary font the boxes will be ragged. There are three weights: light (─ │), heavy (━ ┃) and double (═ ║), and each has its own corners; do not mix them in one box. A folder tree needs just three pieces: ├── for an item, └── for the last item and │ to carry a line down. The shades ░ ▒ ▓ █ make simple bar charts.

Names of the first symbols

Every symbol has an official name in the Unicode standard. Knowing the name helps when you search for it on a phone or in a program's symbol picker.

  • ─ box drawings light horizontal
  • │ box drawings light vertical
  • ┌ box drawings light down and right
  • ┐ box drawings light down and left
  • └ box drawings light up and right
  • ┘ box drawings light up and left
  • ├ box drawings light vertical and right
  • ┤ box drawings light vertical and left
  • ┬ box drawings light down and horizontal
  • ┴ box drawings light up and horizontal
  • ┼ box drawings light vertical and horizontal
  • ━ box drawings heavy horizontal
  • ┃ box drawings heavy vertical
  • ┏ box drawings heavy down and right

Windows Alt codes in this set

30 of these symbols can be typed on a Windows PC by holding Alt and typing a number on the number pad: ─ is Alt + 196, │ is Alt + 179, ┌ is Alt + 218, ┐ is Alt + 191, └ is Alt + 192, ┘ is Alt + 217, ├ is Alt + 195, ┤ is Alt + 180, ┬ is Alt + 194, ┴ is Alt + 193. How it works, and the full list, is on the Alt codes page.

If a symbol shows as a box

Your device has no drawing for it in its fonts. Newer phones show nearly all of these; the reasons and fixes are in why symbols show as boxes.
