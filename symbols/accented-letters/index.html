Accented Letters for French, Spanish, German and More to copy and paste

69 symbols. Tap one to copy it; its name and codes appear at the bottom of the screen.

More about it

What is in this set

Capital and small letters with accents for French, Spanish, Portuguese, German, Italian and the Nordic languages: é, è, ê, ñ, ü, ö, ç, å, ø, and the joined letters æ and œ, with the German sharp s (ß).

How to use them well

You need them for names (José, Zoë, Müller), for words English has borrowed (café, résumé, naïve, jalapeño) and for language homework. Leaving the accent off can change a word: in Spanish, año is "year" and ano is something else. On a phone, hold the plain letter and slide to the accented form. On a Mac, hold the letter key and press the number shown. On Windows each letter has an Alt code from the Western European set; é is Alt + 0233 and ñ is Alt + 0241. The full table is on the Alt codes page.

Windows Alt codes in this set

69 of these symbols can be typed on a Windows PC by holding Alt and typing a number on the number pad: À is Alt + 0192, Á is Alt + 0193, Â is Alt + 0194, Ã is Alt + 0195, Ä is Alt + 142, Å is Alt + 143, Æ is Alt + 146, Ç is Alt + 128, È is Alt + 0200, É is Alt + 144. How it works, and the full list, is on the Alt codes page.

If a symbol shows as a box

Your device has no drawing for it in its fonts. Newer phones show nearly all of these; the reasons and fixes are in why symbols show as boxes.
