Multiplication sign ×: copy, meaning and codes

Copy the multiplication sign with one tap, see what it means and how to type it on Windows, Mac, Android and iPhone, with its Unicode, HTML and CSS codes.

×

Multiplication sign
U+00D7

What it means and how to use it

The proper "times" sign: 6 × 4 = 24. It is also the "by" in sizes (a 10 × 12 foot room, 1920 × 1080 pixels) and marks a cross between plant varieties. It is not the letter x: it sits higher, is symmetrical, and is read as "times" by screen readers. In spreadsheets and programming the asterisk (*) is the multiplication operator, and × will not work in a formula.

How to type it on Windows

Hold the Alt key, type 0215 on the number pad at the right of the keyboard, and let go of Alt. Type the zero at the front: without it you get a different character. Num Lock must be on, and the number keys above the letters do not work for this. In Word, Outlook and WordPad you can type 00D7 and then press Alt + X. In any program, press the Windows key and the full stop together to open the symbol panel and search for it.

How to type it on a Mac

There is no single-key shortcut on the standard layout. Press Control + Command + Space to open the Character Viewer and type "multiplication" in its search box.

On Android and iPhone

Phone keyboards keep the common signs on the symbols pages (?123 on Android, 123 then #+= on iPhone), and many more appear when you hold a related key. If you cannot find this one, tap Copy on this page and paste it into your app.

In a web page

If your page is saved as UTF-8, you can paste × straight into the HTML. To be safe in any encoding, write its code instead: <p>&times;</p>. In a style sheet use content: "\00D7", and in JavaScript "\u00D7".

If it shows as a box

The official Unicode name of this character is "multiplication sign". A device or font that has no drawing for it shows an empty box instead; the character is still there and will appear correctly for readers whose devices have it. See why symbols show as boxes.
