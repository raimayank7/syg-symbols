Hash sign #: copy, meaning and codes

Copy the hash sign with one tap, see what it means and how to type it on Windows, Mac, Android and iPhone, with its Unicode, HTML and CSS codes.

#

Hash sign
U+0023

What it means and how to use it

In India and Britain it is the hash; in North America the pound sign or number sign, as in #2 pencil. On phones it is a key for menus. Since 2007 it has marked a topic on social media, the hashtag. It is not the musical sharp ♯.

How to type it on Windows

This symbol has no Alt code of the classic kind. In Word, Outlook and WordPad you can type 0023 and then press Alt + X. In any program, press the Windows key and the full stop together to open the symbol panel and search for it.

How to type it on a Mac

There is no single-key shortcut on the standard layout. Press Control + Command + Space to open the Character Viewer and type "hash" in its search box.

On Android and iPhone

Phone keyboards keep the common signs on the symbols pages (?123 on Android, 123 then #+= on iPhone), and many more appear when you hold a related key. If you cannot find this one, tap Copy on this page and paste it into your app.

In a web page

If your page is saved as UTF-8, you can paste # straight into the HTML. To be safe in any encoding, write its code instead: <p>&num;</p>. In a style sheet use content: "\0023", and in JavaScript "\u0023".

If it shows as a box

The official Unicode name of this character is "number sign". A device or font that has no drawing for it shows an empty box instead; the character is still there and will appear correctly for readers whose devices have it. See why symbols show as boxes.
