Alt codes for Windows

Hold Alt, type the number on the number pad, let go. Both families of codes are listed here in full; tap a code to copy its symbol instead.

How to use an Alt code

  1. Check that Num Lock is on.
  2. Hold down the left Alt key.
  3. Type the number on the number pad at the right of the keyboard, not on the row above the letters.
  4. Let go of Alt.

Why there are two lists

The same number can give two different symbols, depending on whether you type a zero first. Alt + 248 is the degree sign, and so is Alt + 0176; but Alt + 176 is a shaded block, and Alt + 0248 is the letter ø. The reason is history. Codes without a zero look the symbol up in the character set of the first IBM PC of 1981, known as code page 437, which had smiley faces, card suits and box-drawing lines. Codes with a leading zero use the Windows Western European set, known as Windows-1252, which has the accented letters, curly quotes and signs such as ©, ® and ™. Most people need the second list more.

The lists below are for Windows set to English, as it is on nearly all computers sold in India. On a system set to another language family the codes without a zero can give different characters.

No number pad?

Alt codes need a number pad. On a laptop without one, press the Windows key and the full stop to open the symbol panel, or simply tap a row below to copy the symbol. Other ways are on how to type symbols on Windows.

The most used Alt codes

  • Alt + 0176 for the degree sign °
  • Alt + 0169 for ©, Alt + 0174 for ®, Alt + 0153 for ™
  • Alt + 0128 for the euro sign €, Alt + 0163 for £
  • Alt + 0149 or Alt + 7 for the bullet •
  • Alt + 0133 for the ellipsis …, Alt + 0150 for the en dash, Alt + 0151 for the em dash
  • Alt + 0177 for ±, Alt + 0215 for ×, Alt + 0247 for ÷
  • Alt + 0178 and Alt + 0179 for ² and ³, Alt + 0189 for ½
  • Alt + 3 for ♥, Alt + 13 for ♪, Alt + 24 to 27 for the arrows ↑ ↓ → ←
  • Alt + 251 for the square root sign √, Alt + 236 for ∞, Alt + 227 for π

The rupee sign ₹ and the tick ✓ have no Alt code in either list, because they are not in these two old character sets. Copy them from their pages: rupee sign, check mark.

What about codes above 255?

You may read that Alt + 8377 types ₹ or Alt + 10003 types ✓. Such large codes work only in a few programs, such as Word and WordPad, and not in browsers or most other apps. In Word the dependable method is the hex code followed by Alt + X: type 20B9, then press Alt + X. Every symbol page on this site gives that code.
