Bullet Point Symbols to copy and paste

32 symbols. Tap one to copy it; its name and codes appear at the bottom of the screen.

More about it

What is in this set

Marks to start the lines of a list where there is no list button: in a WhatsApp message, an Instagram bio, a plain email, a note on the phone. The round bullet (•) is the standard; the others add emphasis or a second level.

How to use them well

Good lists use at most two kinds of bullet: one for main points and a lighter one, such as ◦ or ‣, for points under them. Put a space after the bullet. Arrows (➤ ►) suit steps and calls to action; ticks (✓) suit lists of features or things done. On a Mac, Option + 8 types the bullet. On Windows it is Alt + 7 on the number pad, or Alt + 0149. On an iPhone, hold the hyphen key and the bullet appears among the choices.

Names of the first symbols

Every symbol has an official name in the Unicode standard. Knowing the name helps when you search for it on a phone or in a program's symbol picker.

Windows Alt codes in this set

7 of these symbols can be typed on a Windows PC by holding Alt and typing a number on the number pad: • is Alt + 7, ∙ is Alt + 249, ○ is Alt + 9, ■ is Alt + 254, ► is Alt + 16, » is Alt + 175, › is Alt + 0155. How it works, and the full list, is on the Alt codes page.

If a symbol shows as a box

Your device has no drawing for it in its fonts. Newer phones show nearly all of these; the reasons and fixes are in why symbols show as boxes.
