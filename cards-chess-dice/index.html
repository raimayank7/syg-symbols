Playing Card, Chess and Dice Symbols to copy and paste

26 symbols. Tap one to copy it; its name and codes appear at the bottom of the screen.

More about it

What is in this set

The four card suits in black and white forms, all twelve chess pieces, and the six faces of a die. With them you can write down a card hand, a chess position or a dice roll in plain text.

How to use them well

The chess pieces come as a white set (♔ ♕ ♖ ♗ ♘ ♙) and a black set (♚ ♛ ♜ ♝ ♞ ♟). On a dark screen the "white" pieces, which are outlines, may look darker than the solid "black" ones, so name the colour in words when it matters. The black pawn (♟) is drawn as an emoji on some phones. The four suits were among the first symbols on home computers: Alt + 3, 4, 5 and 6 on the Windows number pad still type ♥ ♦ ♣ ♠.

Windows Alt codes in this set

4 of these symbols can be typed on a Windows PC by holding Alt and typing a number on the number pad: ♠ is Alt + 6, ♣ is Alt + 5, ♥ is Alt + 3, ♦ is Alt + 4. How it works, and the full list, is on the Alt codes page.

If a symbol shows as a box

Your device has no drawing for it in its fonts. Newer phones show nearly all of these; the reasons and fixes are in why symbols show as boxes.
