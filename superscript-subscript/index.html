Symbols

Superscript and Subscript Numbers and Letters to copy and paste

38 symbols. Tap one to copy it; its name and codes appear at the bottom of the screen.

More about it

What is in this set

Small raised and lowered digits that work in plain text, where there is no formatting button: m², x³, H₂O, CO₂, 10⁻³. The set has all ten digits in both positions, plus and minus signs, brackets, and the few letters that Unicode provides.

How to use them well

Use these in chat messages, file names, social media posts and spreadsheet labels. In a word processor or on a web page, real formatting is better: Ctrl + Shift + = for superscript and Ctrl + = for subscript in Word, or the <sup> and <sub> tags in HTML. The reason is that the ready-made characters are a small, incomplete set (there is no superscript q, for example) and they may come from a different font and look uneven. Alt + 0178 and Alt + 0179 type ² and ³ on Windows.

Windows Alt codes in this set

6 of these symbols can be typed on a Windows PC by holding Alt and typing a number on the number pad: ¹ is Alt + 0185, ² is Alt + 253, ³ is Alt + 0179, ⁿ is Alt + 252, ª is Alt + 166, º is Alt + 167. How it works, and the full list, is on the Alt codes page.

If a symbol shows as a box

Your device has no drawing for it in its fonts. Newer phones show nearly all of these; the reasons and fixes are in why symbols show as boxes.
