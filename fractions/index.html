Fraction Symbols to copy and paste

20 symbols. Tap one to copy it; its name and codes appear at the bottom of the screen.

More about it

What is in this set

Ready-made fractions as single characters: half, thirds, quarters, fifths, sixths, eighths, and one seventh, ninth and tenth. They are useful in recipes, measurements and sizes, where "1½ cups" reads more cleanly than "1 1/2 cups".

How to use them well

Only these fractions exist as single characters. For any other, such as 7/16, type the digits with the fraction slash (⁄), the last symbol in this set. Many modern fonts will then draw it as a proper small fraction; where they do not, it still reads correctly. Do not use these characters in a spreadsheet cell that must be calculated: the program sees ½ as text, not as 0.5. On Windows, Alt + 0189 types ½, Alt + 0188 types ¼ and Alt + 0190 types ¾.

Windows Alt codes in this set

3 of these symbols can be typed on a Windows PC by holding Alt and typing a number on the number pad: ½ is Alt + 171, ¼ is Alt + 172, ¾ is Alt + 0190. How it works, and the full list, is on the Alt codes page.

If a symbol shows as a box

Your device has no drawing for it in its fonts. Newer phones show nearly all of these; the reasons and fixes are in why symbols show as boxes.
